## Wave 1 of the UI & feature pass

Plan and research record: `docs/UI-FEATURE-PASS.md`. This is the design-system and
motion wave, applied from the `better-ui` skill against this repo's own tokens.

### What changed, and what it was doing wrong

| Change | Why |
|---|---|
| `Button` presses to `scale(0.96)` | No press feedback existed; the control did not acknowledge the click. `static` opts out where motion would distract (icon toggles, toolbar swatches) |
| Focus ring is now a saturated blue in both themes | `--ring` was `oklch(0.708 0 0)` — **2.3:1** on white, below the 3:1 a focus indicator needs. Keyboard users had a ring that was present and invisible |
| Theme switch suppresses transitions | A theme flip changes colour/background/border/shadow on nearly every element at once, so all of those animated together and the page smeared |
| State icons cross-fade | eye/eye-off, link/unlink and sun/moon hard-toggled. Now opacity/scale/blur with both icons mounted — no dependency, no layout shift |
| Elevation is shadows, borders are structure | Cards were using borders for depth. Three layered elevations per theme; dark-mode alphas are raised because a light-mode shadow is invisible on a dark surface |
| `prefers-reduced-motion` is global | It only covered the marketing animations, so the app animated regardless of the preference |
| Icon stroke matched to text weight | Lucide's 2px reads heavy beside the app's medium-weight labels; 1.5px now carries the same optical weight |
| `transition-all` gone (10 files) | It animates layout properties the browser should not be touching |
| `sonner` removed | Both `sonner` and `react-hot-toast` were installed; only the second was ever used |

### Proof

`test/ui-polish.test.ts` (13 tests) asserts each of these against the source: no
`transition-all` anywhere, the exact press value, the transition property list, the
focus-ring contrast ratio computed from the real `--ring`/`--background` tokens in both
themes, three layered elevations per theme with dark alphas above light, the global
reduced-motion block, the theme-swap suppression plus its forced reflow, the prescribed
cross-fade values, and both icons staying mounted.

Every motion change also keeps its static cue (colour, icon or label), so motion is never
the only feedback channel.
